White Draft Pro Privacy Policy

Support

Help for White Draft Pro on macOS.

Open a GitHub Issue.

Include:

  • macOS version (Apple menu → About This Mac)
  • White Draft Pro version (White Draft Pro → About White Draft Pro)
  • What you were doing, and what happened

Requirements

macOS 15 Sequoia or later. Apple Silicon or Intel Mac that can run Sequoia.

Files

White Draft Pro only opens and saves files you pick. If a document will not open, attach it to the issue if you can share it, or describe the format.

Privacy

The app does not create an account and does not send documents to a server. Read the Privacy Policy.
